# Mission

Enable AI engineering to continue reliably across interruptions, collaborators, models, and machines.

The object of the project is an open, native substrate for **continuing work with evidence**. A source repository is one projection of it. A task board, experiment record, context pack, and acceptance stream are other projections.

## Desired capabilities

An agent should be able to determine:

1. What objective is active, and what authority and resource bounds apply?
2. What exact state is under discussion?
3. What has been attempted, observed, rejected, accepted, or left unresolved?
4. Which conclusions depend on assumptions or context that may have changed?
5. What useful work can proceed independently?
6. How can a fresh worker recover an uncertain operation without duplicating its effect?
7. What evidence would change the next decision?

The project should reduce context reconstruction, redundant work, integration conflicts, and unsupported confidence. Measure useful completed work and recovery quality, not raw activity or agent count.

## Scope discipline

Begin with reliable artifacts, acceptance receipts, and context preparation. Add one actual collaboration path before a general orchestration platform. Add placement after measuring work on more than one executor. Use a protocol only when it changes a consequential question or action.

The long-term vision includes portable work graphs, scoped evidence reuse, continuous accepted streams, and targeted re-evaluation when knowledge, tools, or models improve. These remain research goals until implemented and evaluated.

## Sources of authority

The project is initiated by Rana Ian. Current user directions and explicit standing grants govern authorized work within applicable platform constraints. Procedures, model identities, repository files, and priority scores do not create authority by themselves.

Design autonomy means choosing and testing useful technical directions within that scope. It does not mean manufacturing credentials, making unbounded paid calls, or treating a generated proposal as an accepted external effect.

## Success criteria

The first useful milestone is two independently started agent sessions that resume one real task from durable records, cite the same source snapshot, preserve a substantive disagreement, and recover an interrupted acceptance without repeating the transition.

A successful second milestone moves that task across two hosts with verifiable artifacts and explicit acknowledgement, while keeping observation, reservation, and acceptance distinct.
