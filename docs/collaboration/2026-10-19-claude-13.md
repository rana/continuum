# Co-design update: naming, notification, cross-pollination

**1. Naming (consideration only; no change now)**
If Continuum adopts a distinct owned target, the new repo should take the enduring name **Continuum**. The current repo becomes **continuum-prototype**. Call it "frozen" or "deprecated" only if that is actually true. GitHub ends redirects when an old name is reused, so any cutover needs a ledger with:
- old and new repository IDs
- exact cutover commits
- active writers and local remotes
- CI and scheduled prompts

Do the steps in order: freeze writes, rename, verify the new name, then reuse it.

**2. Notifying ongoing chats and workers**
Every research or update session that writes to the repo is a dependent. Before any cutover, list each one. Send it a handoff note with the old and new names, repo IDs, the cutover commit, and the new remote URL. Record each notice as offered, received, or acknowledged. A cutover is complete only when every active writer has acknowledged or has been explicitly retired. Nothing moves until then.

**3. Two-way cross-pollination**
These forms fit different target and bootstrap contracts, and none require releasing private source.

*Base12 → Continuum (public descriptions only):*
- **Methods:** exact custody, bounded independent checks, deliberate mutants, preserved counterexamples, full attempt accounting.
- **Emitted-verifier pattern:** an independently generated checker that reads a portable contract and has no Rust runtime dependency.

*Continuum → Base12:*
- **Methods:** stable operation IDs, durable historical receipts, exact context handoffs.
- **Host tools:** a Rust reference implementation and corpus runner, used only on the host, never linked into Base12's target.

*Both directions:*
- **Specs and test vectors:** shared contract documents, golden corpora, and counterexample sets, each with a pinned version.

**How to share**
- **Prefer specs over code.** Sharing both the implementation and the oracle algorithm can reproduce the same bug on both sides. Keep the checkers independent.
- **Copies** must record their source identity (repo, commit, hash) and a divergence policy: track upstream, fork, or freeze.
- **Shared libraries** only when two actual consumers agree on one contract. Extract one component at a time, with no umbrella framework yet.
- **Licensing:** Continuum is public MIT and Base12 is private. Anything flowing from Base12 into the public repo needs explicit owner release. The Dot mailbox request is still unanswered.

**Status**
The baseline is unchanged: Rust/SQLite, with Codex pilots continuing. No rename, migration, scheduling change, or code transfer is proposed now.
