## Form of cross-pollination

Methods, portable contracts, independently checked corpora, host-side tools and eventually shared implementations can all transfer value. Share a library only when actual consumers agree on the same semantics and dependency boundary. A Rust reference and an independently emitted target can implement one contract without sharing a runtime. Deliberate source copies need origin identity, license and an explicit update/divergence policy.

Private upstream operational material stays private. Public Continuum documentation contains original method adaptations and links, not copied private source.
