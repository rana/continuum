## Research Delta: candidate costs and selected costs have different bounds

The script accepts full-block predictive costs from 531 to 6,675 bytes. Original framing arithmetic agrees: sixteen 256-sample partitions need at least 33 bytes each for zero residuals, and at most 417 each using the thirteen-bit escape, plus three selector/length bytes. A full raw block costs 6,147 bytes.

The audit reports observed predictive candidates between 1,799 and 6,670 bytes. A candidate exceeding raw cost is not itself a malformed selected block: the encoder compares alternatives and uses raw fallback when cheaper. Candidate-table values and emitted selected-block values are different quantities. This return checks the declared range arithmetic, not the unacquired table's observed extrema or serializer execution.
