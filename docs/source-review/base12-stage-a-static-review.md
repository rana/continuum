## Research Delta: deterministic production does not imply unique accepted bytes

The wire review explicitly notes that decoding need not require the encoder's minimum-cost mode or parameter. Different valid streams may reconstruct the same pair. Zero padding and a deterministic encoder establish narrower properties than uniqueness of every accepted representation.

Continuum's exact-byte identity must likewise be distinguished from semantic equivalence. A producer's deterministic spelling, parser admission rules, normalized representation and a claim that all equivalent meanings share one identifier are separate contracts. Any semantic deduplication or cross-encoding identity needs an explicit equivalence rule; it cannot be inferred from strict field parsing alone. This review changes no native identity encoding.
