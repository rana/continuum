# Research records

This directory preserves actual work records and verification evidence. It is not an automatic scheduler.

- [Claude exchange 1 metadata](runs/claude-01.json)
- [Claude exchange 2 metadata](runs/claude-02.json)
- [Foundation verification](runs/foundation-verification.json)

An execution record captures observed metadata, requested settings, and uncertainty. A provider-reported model string does not prove an exact hidden model revision. The proposed schema is [execution-record.schema.json](../schemas/execution-record.schema.json).

Future investigations should preserve original attempts, hypotheses, counterexamples, comparison conditions, and reasons to revisit. Follow the [Research Record](../protocols/research-record.md) procedure when it serves the work.
