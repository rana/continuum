## What using it taught us

**Source retrieval is a useful separate step.** The pack carried enough to select the next action, but source and the existing test harness were necessary to implement it. The receiver's metadata says the native anchor/hash/budget fields did not affect its code; those fields still served coordinator custody and reconstruction. An unused model field is not evidence that its integrity function should be removed. A source retrieval turn resolved speculative concern about additional statistics without adding fields to WorkState. There is no demonstrated need to put every source file into the rendering.

**Exact build binding produced a real negative finding.** After `cargo test --all-features`, `target/debug/continuum` had different bytes from the originally measured default-feature build. The next checkpoint [refused the mismatched digest before creating output](binary-mismatch-observation.json). The coordinator used the earlier checkpoint's retained measured runtime, with unchanged provenance, and produced the [completed checkpoint](completed-checkpoint/). This is observed mismatch rejection and successful reuse of retained executable bytes, not an upgrade or backup test.

**Attempt-history import remains awkward.** Both independent checkpoints have empty native `attempts`: the adapter has no input mechanism to import the existing request/receipt blobs and source snapshots referenced by a continuing attempt. The actual model exchanges and execution results remain exact sidecar evidence, and the completed WorkState carries only an explicitly authored summary. This repeats the first pilot's documented limitation and now justifies a small targeted follow-up: explicit object-closure import with a real recorded-attempt reconstruction test. It does not justify a general model runner or new native evidence-truth claim.

**Success is narrower than comparative benefit.** One actual successor completed this requirement change, and the coordinator checked its consequence. The task, extra retrieval and authoring were arranged by the coordinator. No GitHub-notes baseline, randomized comparison, general quality estimate, measured authoring/upkeep time or financial cost is established. Model output was not independently empirical confirmation; the executable checks support the specific behavioral result. No extra native fields or source-selector changes were needed for the CSV vocabulary.
